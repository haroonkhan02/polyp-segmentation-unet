## Highlights

- **Complete, reproducible pipeline** — one command each to download Kvasir-SEG, train, evaluate, predict and launch a demo. A seeded 80/10/10 split is committed, so the test set is fixed and touched once.
- **U-Net with a pretrained ResNet-34 encoder**, trained with BCE + soft Dice on an Apple M5 GPU (MPS) in 39 minutes.
- **Uncertainty you can check** — `Dropout2d` after every decoder block stays on at test time (MC dropout). The std map is evaluated as an *error detector*: pixel-level AUROC 0.906, and the model's uncertainty is 10.0× higher on the pixels it gets wrong.
- **Error analysis, not just a mean** — per-image Dice histogram, Dice stratified by polyp size, a worst-cases gallery and Dice-vs-uncertainty scatter, all generated by `polyp-evaluate`.
- **Tested without data** — 26 unit tests on synthetic images (augmentation alignment, loss limits, metric identities, MC-dropout stochasticity, checkpoint round-trip) run in CI on Python 3.10–3.12.

## Results

Held-out **test split: 100 Kvasir-SEG images** (seed-0 split in [`configs/split.json`](configs/split.json)), threshold 0.5, original resolution. Checkpoint = best validation Dice (epoch 38 of 40). Inference time is for a 320×320 forward pass on an Apple M5 (MPS), excluding I/O.

| Prediction | mean Dice ↑ | mean IoU ↑ | Precision | Recall | Dataset-level Dice | ms / image |
|---|---|---|---|---|---|---|
| Deterministic (dropout off) | **0.908** | **0.848** | 0.939 | 0.902 | 0.906 | 7.2 |
| MC-dropout mean (20 passes) | 0.908 | 0.847 | 0.937 | 0.903 | 0.905 | 168 |

*Mean Dice/IoU average the per-image scores (the convention in Kvasir-SEG papers); dataset-level Dice pools all pixels and is dominated by large polyps.*

**By polyp size** (fraction of the frame covered by the ground-truth mask):

| Polyp size | Images | mean Dice | mean IoU | Recall |
|---|---|---|---|---|
| small (<5%) | 16 | 0.893 | 0.824 | 0.910 |
| medium (5-20%) | 51 | 0.934 | 0.885 | 0.934 |
| large (>20%) | 33 | 0.876 | 0.802 | 0.850 |

**Is the uncertainty useful?** (MC dropout, 20 stochastic passes)

| Check | Value | Meaning |
|---|---|---|
| Mean std on mis-classified pixels | 0.104 | vs. 0.010 on correct pixels → 10.0× higher where the model is wrong |
| Pixel-error AUROC of the std map | 0.906 | 0.5 = noise, 1.0 = perfect error detector |
| Spearman(image Dice, mean std) | -0.28 | negative = the model is more uncertain on the frames it segments badly |

**What the numbers say**

- **A plain U-Net with a pretrained encoder gets to 0.91 mean Dice on Kvasir-SEG in under 40 minutes on a laptop GPU.** 76 of 100 test images score above 0.9 and the median is 0.95, so the mean is pulled down by a handful of hard cases rather than by general sloppiness.
- **Errors are misses, not false alarms.** Precision (0.94) is higher than recall (0.90) and every one of the worst cases is under-segmentation of a flat or multi-part polyp. Large polyps (> 20 % of the frame) are the weakest group, not the small ones: when a polyp fills the frame its boundary is a subtle texture change rather than a clear edge.
- **The uncertainty map is a good boundary-error detector and a poor miss detector.** Per pixel, std is 10× higher where the model is wrong (AUROC 0.91), so a UI could draw a reliable "fuzzy edge" band. Per image, the correlation with Dice is weak (Spearman −0.28): the worst case has one of the *lowest* mean uncertainties, because MC dropout only captures disagreement between dropout samples and all of them agreed the flat extension was mucosa. Catching those would need test-time augmentation, an ensemble or out-of-distribution signals.
- **Averaging 20 MC passes does not improve Dice** (0.908 vs 0.908) at 23× the inference cost; its value here is the uncertainty, not the mask.
- **No overfitting at this budget**: train and validation loss meet at ≈0.10 by epoch 30 and validation Dice plateaus at 0.90 from epoch 27, so the gains left are in data (more centres, negatives) and architecture, not in longer training.

> **Caveats.** 100 test images give roughly ±0.03 of noise on the mean Dice; the split is my own (there is no official one), so numbers are not strictly comparable to papers; and every Kvasir-SEG frame contains a polyp, so the false-positive rate on healthy mucosa is *unknown*.

## How it works

```mermaid
flowchart LR
    A[Kvasir-SEG frame] --> B[Resize 320² · ImageNet norm]
    B --> C[Augment<br/>flips · rot90 · affine · colour · blur]
    C --> D[U-Net<br/>ResNet-34 encoder · ImageNet]
    D --> E[Decoder blocks<br/>+ Dropout2d 0.2]
    E --> F[Sigmoid · threshold 0.5]
    F --> G[Polyp mask]
    E -. dropout kept ON<br/>T = 20 passes .-> H[Mean · std maps]
    H --> I[Uncertainty heatmap<br/>error AUROC · Spearman]
    G --> J[Dice · IoU · P · R<br/>by polyp size · failure gallery]
    G --> K[Gradio demo · predict CLI]
```

**Training.** Loss = ½ BCE + ½ soft Dice: BCE gives stable per-pixel gradients, Dice optimises the overlap we report and ignores the ~90 % background pixels. AdamW with a OneCycle schedule, batch 8, 40 epochs; the checkpoint with the best *validation mean Dice* is kept.

**Uncertainty.** With dropout active at test time, each forward pass samples a slightly different network (Gal & Ghahramani, 2016). Twenty passes are run as one batch; their mean is a cheap ensemble prediction and their per-pixel std is the epistemic uncertainty. `Dropout2d` drops whole channels so the sampled segmentations differ coherently rather than as pixel noise. BatchNorm stays in eval mode throughout.

## Getting started

```bash
git clone https://github.com/haroonkhan02/polyp-segmentation-unet.git
cd polyp-segmentation-unet
uv venv --python 3.12 && source .venv/bin/activate
uv pip install -e ".[demo,dev]"

polyp-download                                   # Kvasir-SEG, 46 MB -> data/Kvasir-SEG/
polyp-train --config configs/kvasir_unet.yaml    # ~39 min on an Apple M5 (MPS)
polyp-evaluate --split test --mc-samples 20      # writes reports/
polyp-predict data/Kvasir-SEG/images/cju0qkwl35piu0993l0dewei2.jpg --mc-samples 20
polyp-demo                                       # http://127.0.0.1:7860
```

Trained weights are not committed (98 MB); `polyp-train` reproduces them in one run. Any config key can be overridden on the command line, e.g. `polyp-train --encoder resnet18 --epochs 20`.

## Design decisions

| Decision | Why |
|---|---|
| Committed seed-0 split instead of an ad-hoc one | Kvasir-SEG has no official split; a fixed file makes every number reproducible and the test set untouchable. |
| Threshold JPEG masks at 127 | Kvasir masks are JPEGs; compression leaves values 1–254 at edges that would become soft, wrong targets. |
| BCE + Dice, not BCE alone | Polyps are often < 10 % of the frame; BCE alone rewards "all background". |
| `Dropout2d` after each decoder block | Channel dropout yields coherent alternative segmentations for MC sampling; per-pixel dropout barely changes a conv feature map. |
| Checkpoint chosen on validation Dice | Select on the metric you report, not on loss. |
| Uncertainty evaluated against errors | An uncertainty map is only useful if it is higher where the model is wrong; AUROC and Spearman make that checkable. |
| Vertical flips and 90° rotations allowed | Endoscopic frames have no canonical orientation (unlike road scenes). |
| Report both per-image and pooled Dice | Papers use the former; the latter hides failures on small polyps. |
